# apps/landing

Static landing page. Generated in Lovable from `docs/Lovable_Landing_Prompt.md`; Lovable is NOT connected to GitHub (D36). Download the code from Lovable, put it here, commit on a branch and open a PR. CI builds it.

Rules: no backend, database, cookies, analytics or third-party scripts; no personal data stored here (D26). The interest form posts to `INTEREST_ENDPOINT`.
Do not edit the same version here and in Lovable at once: the next download would overwrite repo edits. After the first public launch this folder is the source of truth. See `docs/GitHub_Repo_Blueprint.md`, section 4.
