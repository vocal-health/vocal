# Security policy

Report vulnerabilities, leaked secrets or accidental personal data privately, using GitHub's private vulnerability reporting (Security tab) or by email to bailo.jallow@yahoo.com or mbjallow6@gmail.com.

Please do not open a public issue for these. If you find personal data or a recording anywhere in the repository, report it immediately; do not copy or share it.

No real patient data is, or should ever be, in this repository.
